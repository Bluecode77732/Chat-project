# Roadmap

This is the planned-work list previously kept in README.md's "Scale Up In Future" section, moved here
so README can stay focused on the current feature set. Items are carried over verbatim — no new items
have been added and none are prioritized or scheduled yet; treat this as a backlog, not a committed
timeline.

## Backend

- Store conversation list per user (last message, unread message count, etc)
- Group chat rooms (broadcast via `roomId` to multiple participants)
- Let users delete rooms and conversation history
- "User is typing" indicator via Socket.IO event

## Frontend

- Chat room list UI with unread message count
